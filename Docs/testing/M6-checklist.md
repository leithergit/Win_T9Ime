# M6 测试清单：托盘、设置、词库

测试包：`dist/M6/T9Ime-M6-test.zip`（或共享目录里的 `T9Ime-test`）。先用 `start_m5_test.bat` 注册并启动（它会先关旧版本、在新目录注册）。
包内 `VERSION.txt` 写明版本（commit），启动脚本会先显示它。

|---|---|---|---|---|
