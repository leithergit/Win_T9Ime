# M1 真机测试清单（引擎原型）

**目的**：确认输入法引擎（librime + 九键前端）能在公司的 Windows 7 触屏设备上加载和运行。本阶段还没有界面，只跑命令行测试，不需要触摸操作。

**测试包**：`T9Ime-M1-test.zip`（约 30 MB）。不需要安装，也不需要管理员权限。

## 准备

1. 在设备上记录：型号、系统版本（开始 → 运行 → `winver`）、32 位还是 64 位（计算机 → 属性 → 系统类型）。
2. 确认已安装 **SP1** 和 **KB2670838**（控制面板 → 程序 → 查看已安装的更新，搜索 KB2670838）。KB4474419 装了更好，不强制。
3. 把 zip 复制到设备任意目录（路径中有中文也可以），右键 → 全部解压。

## 步骤

| # | 操作 | 预期结果 | 结果（通过/失败） | 备注 |
|---|---|---|---|---|
| 1 | 双击解压目录里的 `run.bat` | 窗口中出现 `PASS basic`、`PASS schemas`、`ALL PASSED` | | |
| 2 | 看每个 PASS 下面的 `engine init: N ms` | N 小于 2000 | | 记录 N |
| 3 | 64 位系统上：在解压目录按住 Shift 右键 → 在此处打开命令窗口，运行 `run.bat x86` | 同样 `ALL PASSED`（32 位程序在 64 位系统上运行） | | 32 位系统跳过 |
| 4 | 在命令窗口运行：`x86\t9repl.exe --data data --user %TEMP%\t9u`（64 位系统用 `x64\`），然后依次输入下面几行，每行回车 | 见下表 | | |

第 4 步的交互输入：

| 输入 | 预期 |
|---|---|
| `k 94664486` | `preedit=[zhong'guo]`，候选第一个是 `中国` |
| `space` | `commit=[中国]` |
| `k 744` | 候选第一个是 `是` |
| `pick 1` | `input=[shi']` |
| `enter` | `commit=[shi]` |
| `quit` | 退出 |

注：命令窗口的字体可能显示不了部分字符（如 emoji 显示为方框），这不算失败。
