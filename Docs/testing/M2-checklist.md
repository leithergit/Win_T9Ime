# M2 真机测试清单（触屏面板，Win7 触屏设备）

**目的**：在公司的 Windows 7 触屏设备上验证九宫格面板能用手指输入中文，并且**点面板时不会抢走输入框的焦点**。
这一阶段还没有接入系统输入法（TSF），文字是模拟键盘送进去的，所以只在测试窗口和记事本里测。

**测试包**：`T9Ime-M2-test.zip`（约 31 MB），免安装，不需要管理员权限。解压方法与 M1 相同。

## 准备

1. 记录设备型号、系统版本（`winver`）、32/64 位、屏幕分辨率、屏幕缩放比例（控制面板 → 显示）。
2. 先双击 `run.bat`，确认仍然 `ALL PASSED`（引擎检查，同 M1）。
3. 双击 `panel.bat`：会出现一个 "T9Ime TestTarget" 窗口（带输入框）和屏幕底部的九宫格面板。任务栏右下角出现一个托盘图标（默认程序图标）。
4. 用手指点一下 TestTarget 的输入框，让它获得焦点（出现闪烁光标）。

## C. 输入模式对比（仅当 A2 或 A1 有问题时做）

`panel.bat` 可以带参数强制输入方式。先在 TestTarget 里关闭上一个面板（托盘右键 → 退出），然后在解压目录里按住 Shift 右键 → 在此处打开命令窗口：

| # | 命令 | 做 A1~A3，记录焦点是否丢失、点击是否有延迟 | 结果 |
|---|---|---|---|
| C1 | `panel.bat touch` | Win7 默认方式（WM_TOUCH） | |
| C2 | `panel.bat mouse` | 触摸被系统转换成鼠标点击 | |
