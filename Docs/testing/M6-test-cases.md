# M6 详细测试用例：托盘、设置窗口、词库

适用版本：`VERSION.txt` 中 commit 为 `87c11b3` 或更新。
测试设备：Win7 触屏机（主要）、Win11 触屏机。除注明"用手指"外，用手指或鼠标均可；两种都试过更好。

## 0. 准备

| 步骤 | 操作 | 预期 |
|---|---|---|
| 0.1 | 关闭所有之前测试时打开的 TestHost、测试窗口；右键托盘里的 T9Ime 图标 →"退出"（没有图标则跳过） | 旧版本全部退出 |
| 0.2 | 双击共享目录里的 `start_m6_test.bat` | 窗口第一行显示 `commit 87c11b3`（或更新），随后依次出现 [1/5]…[5/5]，没有"FAILED" |
| 0.3 | 等脚本打开两个窗口 | 出现"T9Ime TestTarget [tip]"测试窗口和"T9Ime 设置"窗口；任务栏通知区出现蓝底白字"中"的图标（Win7/Win11 可能藏在"^"展开区里，可拖到任务栏上） |

测试过程中脚本会把诊断信息记录到 `results\m6_watch.txt`（30 分钟），测试结束后一并回传。

**注意**：不要直接运行共享目录 `T9Ime-test` 里的程序（会锁住文件，下次更新复制不进去，导致测到旧版本）；启动脚本会先把包复制到本地 `C:\T9Ime-touch-…` 再运行。

**说明**：凡是"应用"后需要"重新部署"的设置，部署需要几秒到十几秒（Win7 较慢）。部署期间键盘面板能显示，但在其他程序里用物理键盘打字会直接出英文字母，部署完成后恢复——这是设计行为。

## A. 托盘

### TC-A1 托盘图标显示中文状态
- 前置：0 已完成。
- 步骤：观察通知区的 T9Ime 图标；鼠标悬停在图标上。
- 预期：蓝底白字"中"；提示文字"T9Ime 九宫格输入法 - 中文"。

### TC-A2 图标随中英切换变化
- 步骤：
  1. 在测试窗口的大输入框里点一下，让键盘面板出现（不出现则左键单击托盘图标）。
  2. 点面板底行的"中/英"键，面板变成英文全键盘。
  3. 观察托盘图标。
  4. 点英文键盘上的"英/中"切回中文，再观察。
- 预期：第 3 步图标变为灰底白字"英"，悬停提示"…- 英文"；第 4 步变回蓝底"中"。

### TC-A3 左键单击显示/隐藏键盘
- 步骤：左键单击托盘图标两次（间隔 1 秒以上）。
- 预期：键盘面板交替显示、隐藏。

### TC-A4 托盘菜单内容
- 步骤：右键单击托盘图标（触屏：长按图标再松开）。
- 预期：菜单依次为：显示键盘（面板显示时为"隐藏键盘"）、停靠到屏幕底部、分隔线、设置…、重新部署、分隔线、退出。点菜单外任意处菜单关闭。

### TC-A5 菜单"停靠到屏幕底部"
- 步骤：拖动键盘面板顶部的横条，把面板拖到屏幕中间；右键托盘 →"停靠到屏幕底部"。
- 预期：面板回到当前屏幕底部正中。

### TC-A6 菜单"设置…"
- 步骤：先关闭设置窗口（若已打开）；右键托盘 →"设置…"；再次选择"设置…"。
- 预期：第一次打开设置窗口（居中）；第二次不会开第二个窗口，而是把已打开的窗口提到最前。

### TC-A7 菜单"重新部署"
- 步骤：关闭设置窗口；右键托盘 →"重新部署"；立即再右键查看菜单。
- 预期：部署期间菜单中"重新部署"为灰色不可点；几秒后托盘弹出气泡"重新部署完成"（Win11 可能显示为通知）。部署后在测试窗口里用物理键盘打 `nihao` 空格，正常出"你好"。

### TC-A8 菜单"退出"与自动恢复
- 步骤：右键托盘 →"退出"；然后点测试窗口的大输入框，用物理键盘打 `nihao` 空格。
- 预期：退出后托盘图标消失、面板消失；打字时输入法自动重新启动 T9Host（托盘图标重新出现），几秒后打字正常（最初一两个字母可能直接出英文，属正常）。

## B. 设置窗口 - 通用

### TC-B1 窗口外观与触摸可用性
- 步骤：从托盘打开"设置…"，用手指依次点三个页签"键盘""输入""词库"。
- 预期：窗口标题"T9Ime 设置"；字号比系统默认大；每个复选框、下拉框、按钮都能用手指准确点中；切换页签时内容随之切换，没有重叠或残影；底部始终有"确定""取消""应用"和左侧状态行。

### TC-B2 确定 / 取消 / 应用
- 步骤：
  1. "键盘"页取消勾选"切换到 T9Ime 时弹出键盘"，点"取消"；重新打开设置。
  2. 再取消勾选它，点"应用"；窗口不关闭；关闭再打开。
  3. 勾回来，点"确定"。
- 预期：1 中设置未改变（仍勾选）；2 中重新打开后是未勾选；3 点确定后窗口关闭，再打开为已勾选。

### TC-B3 设置在重启后保留
- 步骤：改几项设置（如主题深色、大小"大"、繁体）并"确定"；托盘"退出"；在测试窗口的输入框里用物理键盘打几个字母，让输入法自动重新启动 T9Host（托盘图标重新出现）。
- 预期：面板主题、大小、繁体候选与退出前一致。测完把这几项改回默认。

## C. 设置 - 键盘页

### TC-C1 触摸输入框时自动弹出键盘（关）
- 步骤：取消"触摸输入框时自动弹出键盘"，确定；用手指点托盘让面板隐藏；用手指点测试窗口的大输入框。
- 预期：面板不弹出。之后勾回该项再试：面板弹出。

### TC-C2 任何方式聚焦都弹出
- 步骤：勾选"任何方式聚焦输入框都弹出（无触摸屏时）"，确定；隐藏面板；**用鼠标**点测试窗口的数字框。
- 预期：面板弹出且为数字布局。测完取消勾选。
- 补充：取消"触摸输入框时自动弹出键盘"时，该项变灰不可选。

### TC-C3 切换到 T9Ime 时弹出键盘
- 步骤：保持勾选；隐藏面板；点大输入框；用语言栏或 Ctrl+Shift 切到其他输入法，等 2 秒，再切回 T9Ime。
- 预期：切回后面板自动弹出（中文九宫格）。取消勾选后重复：不弹出。测完勾回。

### TC-C4 关闭系统输入面板图标 / 系统触摸键盘自动弹出
- 步骤（Win7）：勾选"关闭系统输入面板图标"（启动脚本已默认开启，应显示为已勾选），用手指点测试窗口的输入框。取消勾选并确定，再用手指点输入框。
- 预期（Win7）：勾选时输入框旁不出现系统输入面板的小图标、屏幕边缘没有输入面板标签；取消后系统图标重新出现。测完重新勾选。
- 步骤/预期（Win11）：该项名为"关闭系统触摸键盘的自动弹出"；勾选时手指点输入框不会弹出系统触摸键盘。

### TC-C5 主题
- 步骤：主题依次选"深色""浅色""跟随系统"，每次点"应用"。
- 预期：深色 → 面板深色；浅色 → 浅色；跟随系统 → Win7 为浅色，Win11 随系统设置。

### TC-C6 键盘大小预设
- 步骤：面板显示时，"键盘大小"依次选"大""小""中（默认）"，每次"应用"。
- 预期：面板按 4:3 比例变大/变小；面板**底边位置和水平中心不变**（向上长高）；"中"恢复默认大小。

### TC-C7 自定义大小
- 步骤：拖动面板顶部横条右端的斜线手柄改变大小；打开设置。
- 预期："键盘大小"显示"自定义（拖动调整的大小）"；不改它直接"确定"，面板大小保持不变。

### TC-C8 停靠到屏幕底部按钮
- 步骤：把面板拖到屏幕上方；在设置"键盘"页点"停靠到屏幕底部"。
- 预期：面板回到屏幕底部正中，设置窗口不关闭。

## D. 设置 - 输入页

### TC-D1 繁体
- 步骤：字形选"繁体"，点"应用"；在面板上打 `94664486`（zhongguo）。
- 预期：不出现"正在重新部署"；候选第一个为"中國"。物理键盘在测试窗口打 `zhongguo` 空格也上屏"中國"。

### TC-D2 简体
- 步骤：字形改回"简体"，"应用"；再打 `94664486`。
- 预期：候选"中国"。

### TC-D3 模糊音 n = l（重新部署）
- 步骤：勾选"n = l"，点"应用"。
- 预期：状态行立即显示"正在重新部署，请稍候…"，"词库"页的四个按钮变灰；数秒后状态行显示"重新部署完成"，按钮恢复。

### TC-D4 模糊音效果
- 步骤（TC-D3 之后）：在面板上打 `54426`（lihao）；在测试窗口用物理键盘打 `lihao`。
- 预期：两处的第一个候选都是"你好"（未开模糊音时是"极高"/"利好"之类）。

### TC-D5 多个模糊音
- 步骤：再勾选"z = zh""in = ing"，应用并等部署完成；面板打 `926`（zao）；物理键盘打 `zao`、`xin` 看候选。
- 预期：面板 `926` 与物理键盘 `zao` 的候选里都出现"找""照"等 zhao 的字；`xin` 的候选里出现"星""行"等 xing 的字。

### TC-D6 物理键盘候选个数
- 步骤：候选个数选 7，应用并等部署完成；在测试窗口用物理键盘打 `shi`。
- 预期：物理键盘候选窗每页 7 个（编号 1–7）。再改回 5 并部署：每页 5 个。
- 说明：只影响物理键盘的候选窗，面板候选栏不受影响。

### TC-D7 恢复默认
- 步骤：取消所有模糊音，候选个数 5，"应用"并等部署完成；面板打 `54426`。
- 预期：第一个候选不再是"你好"。

### TC-D8 部署期间的表现
- 步骤：勾选一个模糊音并"应用"，部署进行时立即在测试窗口用物理键盘快速打 `nihao`，并点面板按键。
- 预期：部署期间物理键盘可能直接出英文字母（不卡死、不报错）；面板可能暂不响应；部署结束后一切正常。测完恢复默认（TC-D7）。

## E. 设置 - 词库页

### TC-E1 准备学习记录
- 步骤：在测试窗口用物理键盘打 `nihao`，用数字键选**第 2 或第 3 个**候选（例如"拟好"）；再打一个不常见的词组并选非首选候选。
- 预期：再次打 `nihao` 时，刚才选的词排到前面（输入法学到了）。

### TC-E2 导出用户词库
- 步骤：词库页点"导出用户词库…"；保存对话框默认文件名为"T9Ime用户词库-年月日.txt"，选桌面，保存。
- 预期：状态行显示"已导出 N 条"（N ≥ 1）；用记事本打开文件，能找到 TC-E1 选的词。

### TC-E3 清空学习记录
- 步骤：点"清空学习记录…"；在确认框先点"取消"；再点一次并点"确定"。
- 预期：取消时什么都不发生；确定后状态行"学习记录已清空"；再打 `nihao`，TC-E1 选的词不再排前面。

### TC-E4 导入用户词库
- 步骤：点"导入用户词库…"，选 TC-E2 导出的文件。
- 预期：状态行"已导入 N 条"；再打 `nihao`，该词重新排到前面。

### TC-E5 导入错误文件
- 步骤：点"导入用户词库…"，选一个与词库无关的文本文件（如 `VERSION.txt`）。
- 预期：不崩溃；状态行显示"已导入 0 条"或"导入失败（文件格式不对？）"；原有学习记录不受影响。

### TC-E6 词库页的重新部署
- 步骤：点"重新部署"。
- 预期：状态行"正在重新部署，请稍候…" → "重新部署完成"；期间四个按钮变灰。

### TC-E7 清空后数据持久
- 步骤：TC-E3 清空后托盘"退出"，重新启动 T9Host（或打字触发自动启动），打 `nihao`。
- 预期：清空的效果在重启后仍然有效（或 TC-E4 导入后的效果仍然有效）。
