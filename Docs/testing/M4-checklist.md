# M4 真机测试清单（触屏面板经输入法上屏、自动弹出与隐藏）

**目的**：在公司的 **Windows 7 触屏设备**上验证：

- 手指点输入框时面板自动弹出，离开时自动隐藏。
- 面板打出的字经输入法上屏。
- 点面板时会自动切换到 T9Ime 输入法。

**测试包**：`T9Ime-M4-test.zip`，解压到固定位置（例如 `C:\T9Ime-test`）。

## 准备

1. 如果装过旧版：右键旧文件夹的 `unregister.bat`，以管理员身份运行，然后**注销或重启一次**，再删除旧文件夹。
2. 双击 `run.bat`，确认 `ALL PASSED`。
3. 右键 `register.bat`，以管理员身份运行。
4. 运行 `x86\t9diag.exe`（64 位系统运行 `x64\t9diag.exe`），确认输出里有 `TIP 64-bit`、`TIP 32-bit` 的路径（32 位系统只有 32-bit）。

**测试窗口**：运行 `x64\test_target.exe`（32 位系统用 `x86\`）。窗口里有三个输入框：上面的大框是普通文本，中间是**数字框**，最下面是**密码框**。

## A. 自动弹出与隐藏（用手指）

先把输入法切到 T9Ime。第一次点输入框时，后台会自动启动 T9Host，稍等 1–2 秒。

| # | 操作 | 预期结果 | 结果 | 备注 |
|---|---|---|---|---|
| A1 | 用手指点测试窗口的大输入框 | 九宫格面板在屏幕底部弹出（中文九键） | | |
| A2 | 用手指点中间的数字框 | 面板切换为数字键盘 | | |
| A3 | 用手指点最下面的密码框 | 面板隐藏 | | |
| A4 | 再点大输入框 | 面板弹出，回到中文九键 | | |
| A5 | 用手指点桌面或任务栏空白处 | 面板在约半秒内隐藏 | | |
| A6 | 用**鼠标**点大输入框 | 面板**不**自动弹出（默认只响应触摸） | | 没有鼠标可跳过 |
| A7 | 右键托盘图标，勾选"任何方式聚焦输入框都弹出"，再用鼠标点输入框 | 面板弹出 | | 测完取消勾选 |
| A8 | 右键托盘图标，取消"触摸输入框时自动弹出键盘"，再用手指点输入框 | 面板不弹出 | | 测完重新勾选 |

## B. 面板输入（经输入法上屏）

| # | 操作 | 预期 | 结果 |
|---|---|---|---|
| B1 | 在大输入框里用面板输入 `94664486`，点候选"中国" | 输入框出现"中国"，光标不离开输入框 | |
| B2 | 用物理键盘打 `ni`（不按空格），再用面板输入 `744` 并点空格 | 键盘打的 `ni` 被替换为"是" | |
| B3 | 面板输入 `9466`（不选词），再用物理键盘打 `a` 和空格 | 面板上的输入被清空，输入框出现"啊" | |
| B4 | 在数字框里用面板点 1、2、3 | 数字框出现 123 | |
| B5 | 在记事本里做 B1 | 同 B1 | |

## C. 自动切换到 T9Ime

| # | 操作 | 预期 | 结果 |
|---|---|---|---|
| C1 | 打开记事本，把输入法切到**英文键盘**（或其他输入法） | 语言栏显示英文 | |
| C2 | 右键托盘图标 → 显示键盘，在面板上输入 `94664486` 并选"中国" | 记事本出现"中国"，语言栏变为 T9Ime | |
| C3 | 接着用物理键盘打 `nihao` + 空格 | 出现"你好"（已切换到 T9Ime） | |

C2 如果失败，请记录：记事本里有没有出现文字，语言栏是否变化。

## D. 稳定性

| # | 操作 | 预期 | 结果 |
|---|---|---|---|
| D1 | 面板弹出状态下，在任务管理器结束 T9Host.exe | 面板消失，程序不崩溃；再点输入框几秒后恢复 | |
| D2 | 连续在两个程序间来回点（记事本 ↔ 测试窗口），各打几个字 | 面板始终跟随当前输入框，文字进入正确的程序 | |
