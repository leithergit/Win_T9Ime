# M3 真机测试清单（物理键盘全拼，输入法本体 TIP）

**目的**：在公司的 Windows 7 设备上验证 T9Ime 作为系统输入法可以用**物理键盘**打全拼。触屏面板还没有接入输入法（M4 做），本清单只测键盘。

**测试包**：`T9Ime-M3-test.zip`。解压到一个**固定位置**（例如 `C:\T9Ime-test`），测试期间不要移动或删除这个文件夹（系统会从这里加载输入法）。

## 准备

1. 先双击 `run.bat`，确认 `ALL PASSED`（引擎检查）。
2. 右键 `register.bat` → **以管理员身份运行**，看到 `Registered.`。
3. 打开记事本，点语言栏（任务栏右下角 CH 图标）→ 选 **"T9Ime 九宫格输入法"**。Win7 也可以按 Ctrl+Shift 轮换。
   - 如果列表里没有，打开 控制面板 → 区域和语言 → 键盘和语言 → 更改键盘，确认"中文(简体)"下有 T9Ime。
4. 语言栏上应显示"中"。第一次打字时后台会自动启动 T9Host（任务管理器里能看到）。
